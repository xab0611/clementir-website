# clementir-website

HAPAG BAKEHOUSE WEBSITE
=======================

Files:
- index.html       Main landing page (HTML only: no inline styles, no <style> block)
- css/style.css    External stylesheet (all styling)

HOW TO PREVIEW
1. Open the hapag-bakehouse-website folder in Visual Studio Code.
2. Open index.html.
3. Right-click and choose "Open with Live Server" (if installed), or open index.html in your browser.

WHAT WAS APPLIED FROM THE COURSE LESSONS
Lab Activity 3 (HTML)
- Paragraphs (<p>) and HTML comments that label every section
- Unordered list (<ul>) for "Birthday and celebration cakes..." (order does not matter)
- Ordered list (<ol>) for "How to order" (order matters)
- <strong> for importance and <em> for emphasis (the brand name no longer uses <em> just for color)
- Table with <caption>, <thead>, <tbody>, <tfoot>, <th scope="col">, <td> and colspan="3"

Final Term Activity 1 (CSS)
- External CSS only: index.html links to css/style.css inside <head>
- Selector map is at the top of style.css (universal, element, class, ID, grouping,
  descendant, child, adjacent sibling, general sibling, pseudo-class, attribute)
- Pseudo-classes: :hover, :focus, :active, :first-child, :last-child, :nth-child(even)
- Attribute selectors: input[type="text"], [required], a[href^="#"]
- Cascade: element rules first, then class rules, then ID rules, then media queries last

IMPORTANT CUSTOMIZATION
- The proposal does not provide an exact street address, opening hours, phone number, product prices, or real customer reviews. Replace the clearly marked placeholders only with confirmed details.
- The order inquiry form is a front-end sample only. It does not send or store orders until connected to a form service or backend.
- Replace the emoji illustration placeholders with your own bakery photos in the Gallery and product sections (images/hapag-hero.jpg is the home screen photo).
- Review and understand the HTML/CSS so you can explain the code during your lab check.
- Logo: inline SVG symbol plus spaced-letter HAPAG wordmark in index.html (header and footer); look: dark red wall, wood slats, orange glow, parquet footer (css/style.css)
